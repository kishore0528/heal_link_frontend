# Heal Link Frontend

**Heal Link Frontend** is the web frontend of the *Heal Link* application — a healthcare-oriented platform built with **Next.js** and **Tailwind CSS**. This project provides a responsive user interface for users to access features related to healthcare services.

---

## 🚀 About

This repository contains the UI layer of the Heal Link platform. It is built with:

- 📌 **Next.js** – React framework for server-side rendering and routing  
- 🎨 **Tailwind CSS** – Utility-first CSS for rapid styling  
- 🛠️ **JavaScript / TypeScript** setup  
- 📦 Modern web toolchain (ESLint, PostCSS, Vercel configuration)

The frontend connects to backend APIs (not included here) to fetch and display health data, appointments, user profiles and more.

---

## 🧩 Features

- 🌐 Responsive healthcare UI  
- 🧠 Easy navigation with Next.js pages and layouts  
- ✨ Tailwind CSS for modern design
